Bienvenidos

Esta es la página principal de un pequeño proyecto web. El objetivo es mostrar que una página puede organizarse en diferentes carpetas para mantener los archivos ordenados.

¿Por qué organizar las carpetas?

HTML

Las páginas HTML se encuentran organizadas dentro de la carpeta correspondiente.

CSS

Los estilos se encuentran separados en la carpeta css.

Páginas

Las páginas secundarias están dentro de la carpeta paginas.

Una idea importante

Cuando los archivos están correctamente organizados, resulta más fácil encontrarlos, modificarlos y mantener nuestro proyecto.
